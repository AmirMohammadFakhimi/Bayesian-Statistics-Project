Phase 0 — Replicating the Published Study

This notebook replicates the one clustering pipeline the paper — Caravita et al. (2026), Pulmonary Circulation, “Hemodynamic-driven staging of HFpEF” — actually reports: unscaled k-means (k=5) on 8 of 14 hemodynamic variables, selected by a stated correlation-threshold rule. script.r (the group’s reference code) contains this pipeline too, but buried inside six variants (scaled/unscaled × continuous-all/continuous-subset/binary); this notebook keeps only the one branch that matches the paper, and derives the variable-selection step from the real published correlation table instead of copying a hardcoded list.

This is pure replication, following their process exactly as reported. Everything about whether their 8 variables (or their k-means method) are actually the right choice for our own model is deferred to Phase 1 (variable assessment) and Phase 2 (the Bayesian model) — this notebook only asks “did we reproduce what they reported.”

Source files: dataset1.txt, dataset2.txt, dataset3.txt — raw per-patient, per-exercise-step right-heart-catheterization data. Each patient has three rows: REST, LEG (“feet on the pedals”), PEAK.

2. Correlation matrix (paper §2.2, e-Table 1)

The real published 14×14 Pearson correlation matrix, transcribed from e-Table 1 in the paper’s Supporting Information — not recomputed, so this is their actual numbers.

For two variables \(x\) and \(y\) measured on the same \(n\) patients, the Pearson correlation coefficient is

\[ r_{xy} = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})} {\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2}\sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}} \]

i.e. the sample covariance of \(x\) and \(y\), normalized by their standard deviations, giving a value in \([-1, 1]\). The paper’s rule — drop one variable from any pair with \(|r_{xy}| \geq 0.80\) — is just a threshold on this quantity, applied pairwise over all \(\binom{14}{2}=91\) pairs.

3. Variable selection — algorithm, then the published list

“In case of high correlation between two variables, we planned to prefer PAWP […] over PA pressure and RAP and to prioritize values averaged throughout the cardiac cycle over end-diastolic or systolic values.”

Coding that rule and applying it to every |r| >= 0.80 pair above:

role = {"PAPM": "PA", "PAPM.CO.f.slp": "PA",
        "PAWP.MIDA": "PAWP", "PAWP.MEDIA": "PAWP", "PAWP_MIDA.CO.f.slp": "PAWP",
        "PAWP.MEDIA.CO.f.slp": "PAWP", "PAWP.V.AMPL": "PAWP",
        "RAP.MIDA": "RAP", "RAP.MEDIA": "RAP", "RAP.MEDIA.CO.f.slp": "RAP", "RAP.VY": "RAP",
        "PVR.MEDIA": "other", "CI": "other", "COVO2.slp": "other"}
cycle = {"PAPM": 0, "PAPM.CO.f.slp": 0,
         "PAWP.MIDA": 1, "PAWP.MEDIA": 0, "PAWP_MIDA.CO.f.slp": 1, "PAWP.MEDIA.CO.f.slp": 0, "PAWP.V.AMPL": 2,
         "RAP.MIDA": 1, "RAP.MEDIA": 0, "RAP.MEDIA.CO.f.slp": 0, "RAP.VY": 2,
         "PVR.MEDIA": 2, "CI": 2, "COVO2.slp": 2}
family_rank = {"PAWP": 0, "other": 0, "PA": 1, "RAP": 1}  # prefer PAWP over PA pressure/RAP

def keep_vs_drop(a, b):
    ra, rb = family_rank[role[a]], family_rank[role[b]]
    if ra != rb:
        return (a, b) if ra < rb else (b, a)
    ca, cb = cycle[a], cycle[b]
    return (a, b) if ca <= cb else (b, a)

survivors = set(hemo_vars)
dropped_by = {}
for (a, b), r in high_corr_pairs.items():
    if a not in survivors or b not in survivors:
        continue
    keep, drop = keep_vs_drop(a, b)
    survivors.discard(drop)
    dropped_by[drop] = (keep, r)

5. k-means clustering — continuous, reduced 8-variable subset, unscaled

“we adopted the k-means clustering method, with the Euclidean distance on the actual measurements without further normalization […] k = 5 was set as the number of clusters.”

Given \(n\) patients as points \(\mathbf{x}_1, \dots, \mathbf{x}_n \in \mathbb{R}^{18}\) (the 18 columns built in Section 4) and a fixed number of clusters \(k\), k-means looks for cluster assignments \(c_i \in \{1,\dots,k\}\) and centroids \(\boldsymbol{\mu}_1, \dots, \boldsymbol{\mu}_k\) that minimize the within-cluster sum of squares (WCSS):

\[ \text{WCSS} = \sum_{j=1}^{k} \sum_{i:\, c_i = j} \lVert \mathbf{x}_i - \boldsymbol{\mu}_j \rVert_2^2, \qquad \boldsymbol{\mu}_j = \frac{1}{|\{i : c_i = j\}|}\sum_{i:\, c_i = j} \mathbf{x}_i \]

— plain squared Euclidean distance, unweighted, exactly as the paper specifies (“without further normalization”: no per-variable scaling, so a variable on a larger numeric scale, like PVR, mechanically dominates the distance over one on a smaller scale, like cardiac index). This has no closed-form solution; sklearn’s KMeans minimizes it by Lloyd’s algorithm (iteratively reassigning points to the nearest centroid, then recomputing centroids) from n_init=10 random starts, keeping the best. \(k\) itself isn’t estimated by this objective — WCSS only ever decreases as \(k\) grows — which is why the elbow plot below is a visual heuristic, not a statistic, and why the paper (and this script) just fixes \(k=5\) by eye.

X_arr = X.drop(columns="ID").to_numpy()

wcss = []
k_range = range(2, 16)
for k in k_range:
    wcss.append(KMeans(n_clusters=k, n_init=10, random_state=RANDOM_STATE).fit(X_arr).inertia_)

fig, ax = plt.subplots(figsize=(7, 5))

ax.set_xlabel("Number of clusters")
ax.set_ylabel("Within-cluster sum of squares")
ax.set_title("Elbow plot (cf. paper e-Figure 1)")

Limitations of this replication

  • Variable selection isn’t fully reproducible. The paper’s stated tie-break rule, applied mechanically to the real correlation table, yields 9 variables; the paper reports 8. The extra survivor (RAP.MEDIA.CO.f.slp) isn’t correlated ≥0.80 with anything else left, so its exclusion isn’t explained by the Methods as written — we drop it anyway to match what they actually report.
  • k is imposed, not inferred. k=5 comes from an “elbow, although not very pronounced” the paper describes qualitatively — not a criterion anyone could re-run and get the same answer from.
  • Cluster assignment is a hard, deterministic label. k-means gives each patient exactly one cluster with no notion of confidence or borderline membership, and is sensitive to initialization — our sizes (18/13/29/8/12) land in the same ballpark as the paper’s (26/30/12/4/8) but don’t match exactly, and there’s no way to tell, from k-means alone, whether that gap is noise or a real difference in cohort/implementation.
  • No uncertainty quantification anywhere — not on cluster count, not on membership, not on the variable-selection step itself.
  • Only 21 of ~124 raw columns were ever considered, and only on the paper’s say-so. Phase 1 goes back to the full raw files and assesses that choice directly, rather than inheriting it uncritically.

This replication’s job ends here. Whether 8 (or 9, or more) variables is the right choice, and what kind of model should actually be built on top of them, is Phase 1 and Phase 2’s job — not re-litigated in this notebook.
